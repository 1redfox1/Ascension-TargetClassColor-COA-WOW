# Ascension-TargetClassColor-COA-WOW
# TargetClassColor  A tiny World of Warcraft 3.3.5 addon that colors the Target Frame by player class.  ## Features  - Class-colored Target Frame - No libraries - No settings - Lightweight - Compatible with WoW 3.3.5 - Tested on Ascension CoA (Rexxar)  ## Installation  Copy the `TargetClassColor` folder into:  Interface/AddOns/
